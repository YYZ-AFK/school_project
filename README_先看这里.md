# 慧医数字医疗应用系统 - 先看这里

这是整理后的可运行版本，包含后端 Spring Boot、前端页面、数据库脚本和一键启动脚本。

## 本机运行

先完整解压项目，不要在压缩包里直接运行。进入项目文件夹后双击：

```text
run.bat
```

或双击：

```text
start-all.bat
```

启动后本机访问：

```text
http://127.0.0.1:5173
```

## 校园网给同学访问

你和同学在同一个校园网时，先运行项目，再让同学打开启动窗口里显示的局域网地址，格式类似：

```text
http://172.x.x.x:5173
```

如果同学打不开，双击：

```text
allow-lan-access.bat
```

出现管理员授权时点“是”，放行后再让同学访问同一个地址。

## 公网访问

需要不在同一校园网的人访问时，先确认本机可以打开 `http://127.0.0.1:5173`，然后双击：

```text
start-public-url.bat
```

窗口里出现 `PUBLIC_URL=https://xxxxx.trycloudflare.com` 后，把这个公网地址发给别人。公网窗口不能关闭，关闭后地址会失效。

如果开着 Clash Verge / Mihomo，请关闭虚拟网卡或 TUN 模式，否则可能出现 `198.18.x.x`、TLS handshake、Bad Gateway 等问题。

## 登录账号

登录账号和密码请向项目负责人获取。说明文件和登录页面不展示真实默认密码。

## 停止项目

需要删除、移动、重新压缩项目文件夹前，先双击：

```text
stop-all.bat
```

它会停止占用 `8080` 和 `5173` 的后端、前端进程。
